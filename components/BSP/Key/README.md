# GPIO25 单按键：收回 / 伸出切换

驱动位于预建的 `Key` 目录：`key.c`、`key.h`。
主程序只使用 GPIO25 的一个按键，GPIO26 不再配置或读取。

## 默认接线

| 功能 | ESP32 引脚 | 接法 |
| --- | --- | --- |
| 收回 / 伸出切换按键 | GPIO25 | GPIO25 → 常开按键 → GND |
| 舵机信号 | GPIO18 | 沿用原来的舵机接线 |

按键使用内部上拉，松开为高电平、按下为低电平。
四脚轻触按键需选用按下后才导通的两个端子；同侧已连通的两个端子不能构成开关。
本驱动要求 GPIO 支持内部上拉，因此不支持经典 ESP32 的 GPIO34～39。
改引脚时修改 `main/main.c` 的 `KEY_GPIO`，
避开当前舵机 GPIO18、雨滴 GPIO27、SHT30 GPIO21/22，以及板载 Flash 等占用的引脚。

## 控制行为

- 启动时沿用舵机驱动的 90° 中位，不再自动往返。
- 初始位置未知时，第一次按下收回到 45°；稳定松开再按，伸出到 135°，之后交替切换。
- 目标角度由 `SERVO_EXTEND_ANGLE`、`SERVO_RETRACT_ANGLE` 修改，需按实物机构标定。
- 按下和松开都要求电平连续稳定 30ms；每次按下只触发一次，长按不重复。
- 上电时已按住的按键不会触发命令，需要先稳定松开再按下。
- 舵机每步改变 1°，两次下发至少间隔 20ms；按键约每 10ms 扫描一次，
  移动中松开并再次按下同一个键，可以改变方向，无需等待原动作完成。
- 切换以当前衣架状态为准。下雨或 RTC 自动收回后，下一次有效按键在无雨时伸出。
  自动事件与按键同时发生时优先收回，不缓存被忽略的伸出请求。
- 舵机命令失败时停止继续下发动作并标记位置未知，下一次按键重新尝试收回。
- 持续有雨时不允许按键伸出，雨停后需重新按下才伸出；SHT30 仍只输出温湿度。
- RTC 每天 18:00 请求收回；按键已经提前收回或正在收回时，不重复动作。

角度表示最后下发的目标值，不代表实际位置反馈。松开按键不会中途停止，
舵机会继续移动到该次按键指定的目标角度。

## 接口

```c
key_t key = {0};
ESP_ERROR_CHECK(key_init(&key, GPIO_NUM_25));

// 在同一任务中周期调用，不需要 GPIO 中断。
key_event_t event;
ESP_ERROR_CHECK(key_poll(&key, &event));
// event 为 KEY_EVENT_NONE / KEY_EVENT_PRESSED。
// 衣架控制任务把 KEY_EVENT_PRESSED 转成 clothes_inputs_t.manual_toggle。
```

`key_poll()` 不延时，使用 `esp_timer_get_time()` 计算稳定时间；消抖由经过的时间决定，
不是调用次数。对象字段由驱动维护，同一对象不能被多个任务同时访问。

## 验证

主机测试命令及覆盖范围见 `tests/README.md`，固件使用 `idf.py build` 编译。
主机测试替代 GPIO 和时间接口，运行实际 `key.c`，验证消抖和事件规则。

上板验收：GPIO25 按下后收回，松开再按后伸出；长按只动作一次，移动中再按可反向。
雨中按键不能伸出，雨停后重新按键应伸出；18:00 提前已收回时仍应跳过重复收回。
检查实际舵机方向与机构限位，再调整角度。软件验证不代替实物接线与机械运动测试。
