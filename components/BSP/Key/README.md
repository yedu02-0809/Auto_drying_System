# 双按键控制：伸出 / 收回

驱动位于预建的 `Key` 目录：`key.c`、`key.h`。
主程序已用双按键控制替换舵机自动往返测试。

## 默认接线

| 功能 | ESP32 引脚 | 接法 |
| --- | --- | --- |
| 伸出按键 | GPIO25 | GPIO25 → 常开按键 → GND |
| 收回按键 | GPIO26 | GPIO26 → 常开按键 → GND |
| 舵机信号 | GPIO18 | 沿用原来的舵机接线 |

按键使用内部上拉，松开为高电平、按下为低电平。
四脚轻触按键需选用按下后才导通的两个端子；同侧已连通的两个端子不能构成开关。
本驱动要求 GPIO 支持内部上拉，因此不支持经典 ESP32 的 GPIO34～39。
改引脚时修改 `main/main.c` 的 `KEY_EXTEND_GPIO` 和 `KEY_RETRACT_GPIO`，
避开当前舵机 GPIO18、雨滴 GPIO27、SHT30 GPIO21/22，以及板载 Flash 等占用的引脚。

## 控制行为

- 启动时沿用舵机驱动的 90° 中位，不再自动往返。
- 按一下伸出键，目标变为 135°；按一下收回键，目标变为 45°。
- 目标角度由 `SERVO_EXTEND_ANGLE`、`SERVO_RETRACT_ANGLE` 修改，需按实物机构标定。
- 两个按键分别消抖，电平连续稳定 30ms 才确认；每次按下只触发一次，长按不重复。
- 上电时已按住的按键不会触发命令，需要先稳定松开再按下。
- 两键同时确认按下时，收回优先；保持收回键时不接受伸出命令。
  松开收回键后，不会执行此前被抑制的伸出命令，需重新松开并按下伸出键。
- 舵机每步改变 1°，两次下发至少间隔 20ms；按键约每 10ms 扫描一次，
  移动中按另一方向的键，可以在消抖确认后改变目标，无需等待原动作完成。
- 舵机命令失败时停止继续下发动作并记录错误，下一次按键可重新尝试。
- 当前雨滴和 SHT30 仍只检测、输出日志，尚未参与自动收回判断。

角度表示最后下发的目标值，不代表实际位置反馈。松开按键不会中途停止，
舵机会继续移动到该次按键指定的目标角度。

## 接口

```c
key_pair_t keys = {0};
ESP_ERROR_CHECK(key_init(&keys, GPIO_NUM_25, GPIO_NUM_26));

// 在同一任务中周期调用，不需要 GPIO 中断。
key_event_t event;
ESP_ERROR_CHECK(key_poll(&keys, &event));
// event 为 KEY_EVENT_NONE / KEY_EVENT_EXTEND / KEY_EVENT_RETRACT。
```

`key_poll()` 不延时，使用 `esp_timer_get_time()` 计算稳定时间；消抖由经过的时间决定，
不是调用次数。对象字段由驱动维护，同一对象不能被多个任务同时访问。

## 验证

主机测试命令及覆盖范围见 `tests/README.md`，固件使用 `idf.py build` 编译。
主机测试替代 GPIO 和时间接口，运行实际 `key.c`，验证消抖和事件规则。

上板验收：分别短按、长按两个键，验证伸出/收回；移动中反向按键应改变方向；
同时按下两键应收回；松开后不能出现之前被抑制的伸出动作。
检查实际舵机方向与机构限位，再调整角度。软件验证不代替实物接线与机械运动测试。
