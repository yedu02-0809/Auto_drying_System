# RTC 时钟与每天 18:00 收衣服

本次按 **DS3231** 模块实现，驱动位于预建的 `RTC` 文件夹。
如果实物是 DS1302、DS1307 或其他型号，不应直接使用本驱动，需先调整协议和接线。

## 接线

| DS3231 | ESP32 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO21 |
| SCL | GPIO22 |
| SQW / 32K | 本功能不接 |

与 SHT30 共用 I2C0，DS3231 地址 `0x68`，SHT30 地址 `0x44`，两者不会地址冲突。
SDA/SCL 使用上拉到 3.3V 的电阻，可复用模块已有上拉，不能上拉到 5V。
引脚在 `main/environment.c` 的 `SENSOR_SDA_GPIO`、`SENSOR_SCL_GPIO` 配置。
安装模块适配的后备电池，才能在 ESP32 断电后继续走时。

## 首次校时

烧录后运行 `idf.py monitor`，串口为 115200 波特率。在 `drying>` 提示符下输入：

```text
rtc_set 2026-09-21 17:59:00
rtc_get
```

上面的日期时间仅为测试示例，实际使用时必须改成**当前北京时间**。
`rtc_set` 请求由 I2C 采集任务执行，看到 `RTC set: ...` 才表示写入成功；
出现 `RTC set failed` 时按错误提示检查模块、日期和接线。随后用 `rtc_get` 查看读回时间。
支持 2000～2099 年，使用 24 小时制。不会每次开机都写编译时间，也不需要 Wi-Fi 校时。

芯片失电/停振后的 OSF 标记表示时间不可信。驱动不会自行清除该标记，
必须显式校时后才启用定时收回。无法通信、时间非法或时间快照超过 3 秒未更新，
都只禁用定时功能，按键和雨滴控制仍可用。

## 收回规则

- 当地时间达到 18:00，当天首次检查触发收回；读取发生在 18:00 之后也能补触发。
- 因按键、下雨等已经收回，或者正在收回时，18:00 只记录已检查，**不再次下发收回**。
- 如果提前收回后又手动伸出，18:00 会再次收回，因为此时衣服在外面。
- 每天的定时检查只执行一次；同一晚手动再次伸出后，不会每秒被定时任务重复收回。
  次日 18:00 重新检查。系统不会在早晨自动伸出。
- 雨滴连续 3 次采样确认有雨时立即请求收回；一直有雨不重复执行，并禁止按键伸出。
  雨停后不自动伸出，需再次按伸出键。读取失败保留最后确认的雨状态。
- 同一轮出现多个请求时，收回优先于伸出，舵机仅由一个控制任务操作。
- 舵机所有角度指令成功下发完毕后，软件才标记“已收回”；命令出错时标记未知，
  停止继续步进，等待下一次按键或新的自动事件重试，不把失败当成收回成功。

时钟回拨到当天或更早日期不会重复执行已处理日期的晚间任务。
若误把 RTC 设到未来再改回来，需重启以清除内存中的已处理日期。
校时到 18:00 之后可能立即触发当日检查，测试时应让机构处于可运动状态。

当前 SG90 没有实际位置反馈，“已收回”是软件指令状态，不能检测堵转或断电。
位置和当天已检查日期只保存在运行内存中，重启沿用原来的 90° 中位，位置重新视为未知；
若此时已过 18:00，会补发收回。需要断电后准确知道机械位置时，必须增加限位/位置反馈。

## 文件与接口

- `rtc.c / rtc_ds3231.h`：`rtc_ds3231_init`、`rtc_ds3231_get_datetime`、`rtc_ds3231_set_datetime`、`rtc_ds3231_deinit`；
  校验 BCD、日历、闰年、OSF，读取兼容芯片 12 小时模式，输出统一为 24 小时制。
- `main/environment.c`：共享 I2C、RTC/SHT30 采集、线程间时间快照和串口校时。
- `components/Middlewares/clothes_control`：独立的收回策略和状态去重。
- `main/main.c`：扫描按键/雨滴，把策略命令转换为舵机平滑步进。

RTC 对象初始化为 `{0}`，所有读写由同一个采集任务串行执行。
RTC API 不拥有总线，释放设备不会释放 SHT30 共用的总线。

## 验证

主机测试命令见 `tests/README.md`；固件通过 `idf.py build` 编译。
实物验收时可先校到当天 17:59 附近，手动伸出并观察到点收回；
再测试提前按键收回或滴水收回，18:00 应输出 `already retracted/retracting, skip`。
重复同一天的定时测试前需重启清除已检查记录，或校到另一天再测。
主机测试不代替实物 RTC 走时、电池保持能力、接线和机械运动验证。

协议依据：[Analog Devices DS3231 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ds3231.pdf)。
