# 面包板接线说明

配套图：[breadboard-wiring.png](breadboard-wiring.png)

## 一、先理解面包板的两条规则

1. **同一列（a~e 或 f~j 的 5 个孔）是连通的**，同一行不连通。所以「一列 = 一个网络」。
2. 中间隔离槽两侧不连通，左右两条电源轨（+ / −）各自是一整条。

这条规则决定了：**两个器件的引脚不能插在同一列的同一段里**，否则会互相短接。
摆模块时先想好「这一列给谁用」，再插。

## 二、逐引脚接线表

颜色和图例一致：3V3 红、GND 黑、5V 蓝、SDA 黄、SCL 绿、信号橙。

| 3V3 | 面包板「3V3 总线」 | 红 | 只给传感器，**不要接舵机** |

## 三、面包板上怎么摆

### 方案 A：一块 830 板（63 排 × 10 列）

把 b、c、d、e 四列当作**总线列**：

| 列 | 网络 |
| --- | --- |
| b | 3V3 |
| c | GND |
| d | SCL |
| e | SDA |

- 模块的四个脚插在 **f~i 列**（右半区），每个模块占自己的一段排，用短线把每个脚拐到 b~e 对应列。
- ESP32 两排针分别插在 **a 列和 j 列**（它宽 0.9 英寸，正好跨到 j 列），所以 a、j 两列不能再给别的器件用。
- 右半区只有 f、g、h、i 四列，**同时只能放一个 4 脚模块**；其余模块放到下方另一段排，
  但注意 e 列已经在用，会和新模块的引脚冲突 —— 这就是为什么建议用方案 B。

### 方案 B：两块板拼起来（推荐，和你现在的一样）

两块板并排拼成 **63 排 × 20 列**：

| 区域 | 用途 |
| --- | --- |
| 左板 b~e 列 | 3V3 / GND / SCL / SDA 四条总线，从上贯到下 |
| 左板 f~i 列 | I2C 四个模块（DS3231、SHT30、BH1750、OLED）各占一段 |
| 右板 | 按键、雨滴、舵机，以及 5V 电源轨 |
| 首尾各一条电源轨 | 红色接 3V3（或 5V），蓝色接 GND |

每块板内部列是连通的，但**两块板之间不连通**，所以跨板要拉 4 根线（3V3、GND、SDA、SCL）把两边的总线连起来。

### 关于「第几排」

排号从有电源轨的那一头开始数，1 ~ 63。建议：

| 器件 | 摆放位置（排） |
| --- | --- |
| OLED | 3 ~ 6 |
| DS3231 | 9 ~ 14 |
| SHT30 | 17 ~ 20 |
| BH1750 | 23 ~ 27 |
| ESP32 | 30 ~ 44（a / j 列） |
| 按键 | 47 ~ 48 |
| 雨滴 | 50 ~ 53 |
| 舵机 | 56 ~ 58 |

这样每个器件上下都留了空排，跳线不会打架。把器件按这个顺序插好后，
再对照上面的表一根根接线，接完用万用表通断档确认：

- 3V3 和 GND 之间**不能导通**（导通就是短路了）
- 每个模块的 VCC 到 3V3 总线要通，GND 到 GND 总线要通
- SDA 到 SDA 总线要通，SCL 到 SCL 总线要通

## 四、上电检查顺序

1. 先不插 ESP32，只接 3V3 / GND 总线，量一下两轨之间电阻，应该是几百欧以上（不是 0）。
2. 插上 ESP32，USB 供电，看串口有没有启动日志。
3. 再逐个插模块，每插一个看一次日志 —— 出问题能立刻定位是哪个模块。
4. OLED 应该显示 `NO RTC`、温湿度、`----lx`；接上 DS3231 后用 `rtc_set` 校时。
5. 舵机**最后**接，并且用独立 5V；如果插上舵机 ESP32 就重启，99% 是供电不足。

## 五、常见问题

| 现象 | 原因 |
| --- | --- |
| I2C 扫描不到任何设备 | SDA/SCL 接反，或者没接上拉（模块自带一般够用） |
| 只有 OLED 亮、传感器读不到 | 总线只连到一块板，另一块板没接线 |
| 舵机一动就重启 | 舵机从 3V3 取电，或者没共地 |
| 屏幕花屏 | SCL 走线太长 / 杜邦线接触不良 / 电源不稳 |
| 温湿度一直是 `NO CLIMATE DATA` | SHT30 地址不对（ADDR 悬空），或没接 3V3 |
