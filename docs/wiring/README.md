# 面包板接线说明

配套图：[breadboard-wiring.png](breadboard-wiring.png)

## 一、面包板的连线规则（先搞清楚这个）

1. **横向一排的 5 个孔是连通的**：a-5、b-5、c-5、d-5、e-5 是一个网络；f~j 同理。
2. **同一列的孔互不相通**（a1 和 a2 是两回事）。
3. 中间隔离槽两侧（e 和 f 之间）不连通。
4. 上下两条电源轨各自是一整条连通的横条。

由此得到两条实用结论：

- **模块要竖着插**：4 个脚各占一排（8、9、10、11 排），每只脚单独占一个网络，
  不会互相短接。横着插同一排会把 4 个脚全部短路。
- **每个脚所在的那一排，剩下 4 个孔就是它的接线区**，可以再插 4 根线。

## 二、孔不够怎么办

一排只有 5 个孔：模块脚占 1 个，剩 4 个。如果这一排已经插了 1 根线（比如 SDA），
就只剩 **3 个孔** —— 这是正常现象，不是板子不够用。

需要再挤出位置时，有三种办法：

| 办法 | 做法 | 效果 |
| --- | --- | --- |
| **并联相邻排**（最常用） | 用一根 2 cm 短跳线，把这一排的一个空孔连到**相邻空排**的任意孔 | 立刻多出 5 个孔，两排变成同一个网络 |
| **借另一侧** | 中间槽不连通，所以 f~j 那半排是独立的 5 个孔 | 多 5 个孔 |
| **走电源轨** | 3V3、GND 用上下那两条长轨，整条都能插 | 不占主区孔位 |

**四条 I2C 线的现实接法**：不要指望一排塞下四个模块的 SDA，用「链式」：
从 ESP32 的 GPIO21 引出 → 接到 OLED 那一排的空孔 → 再从 OLED 那排的另一个空孔接到
DS3231 那排 → 依次串下去。每一段都是一根独立的跳线。

## 三、逐引脚接线表

颜色和图例一致：3V3 红、GND 黑、5V 蓝、SDA 黄、SCL 绿、信号橙。

### ESP32 ↔ 总线

| ESP32 引脚 | 接到 | 颜色 | 说明 |
| --- | --- | --- | --- |
| 3V3 | 电源轨「+」 | 红 | 只给传感器，**不要接舵机** |
| GND | 电源轨「−」 | 黑 | 所有模块共地，必须接 |
| VIN / 5V | 舵机 VCC（或独立 5V） | 蓝 | 舵机电流大，别走 3V3 |
| GPIO21（SDA） | 各模块 SDA 链 | 黄 | I2C 数据，四个器件共用这一根 |
| GPIO22（SCL） | 各模块 SCL 链 | 绿 | I2C 时钟，四个器件共用这一根 |
| GPIO18 | 舵机 PWM | 橙 | 50 Hz PWM |
| GPIO25 | 按键一端 | 橙 | 另一端接 GND |
| GPIO27 | 雨滴 DO | 橙 | 低电平 = 有雨 |

### 四个 I2C 器件

四个器件挂**同一条** SDA/SCL（GPIO21/22），靠地址区分，不会冲突。

| 器件 | 引脚 | 接到 | 备注 |
| --- | --- | --- | --- |
| **DS3231** | VCC / GND | + / − | |
| | SCL / SDA | SCL 链 / SDA 链 | |
| | 32K / SQW | **不接** | 本工程不用中断输出 |
| **SHT30** | VCC / GND | + / − | |
| | SCL / SDA | SCL 链 / SDA 链 | |
| **BH1750** | VCC / GND | + / − | |
| | SCL / SDA | SCL 链 / SDA 链 | |
| | ADDR | −（GND） | 接地 = 地址 `0x23`；接高是 `0x5C` |
| **OLED** | GND / VCC | − / + | 模块丝印顺序 GND/VCC/SCL/SDA |
| | SCL / SDA | SCL 链 / SDA 链 | |

地址：DS3231 `0x68`、SHT30 `0x44`、BH1750 `0x23`、OLED `0x3C`，互不相同。

### 其他器件

| 器件 | 引脚 | 接到 | 备注 |
| --- | --- | --- | --- |
| **按键** | 一端 | GPIO25 | 四脚轻触键选「按下才导通」的两个端子 |
| | 另一端 | −（GND） | 内部上拉，按下拉低 |
| **雨滴模块** | VCC / GND | + / − | 先确认模块支持 3.3 V |

| | AO | **不接** | 本工程不读模拟量 |

| | GND（棕） | −（GND） | 必须和 ESP32 共地 |
| | PWM（橙） | GPIO18 | 50 Hz，1000–2000 µs |

## 四、摆放建议

模块竖着插，每个模块占连续的几排，彼此间隔 2～3 排留出走线空间：

| 器件 | 占用排 | 插在哪一列 | 脚数 |
| --- | --- | --- | --- |
| OLED | 3 – 6 | b | 4 |
| SHT30 | 9 – 12 | b | 4 |
| DS3231 | 15 – 20 | b | 6 |
| BH1750 | 23 – 27 | b | 5 |
| ESP32 | 30 – 44 | a 列 + j 列 | 15 + 15 |
| 按键 | 47 – 48 | b | 2 |
| 雨滴 | 51 – 54 | b | 4 |
| 舵机 | 57 – 59 | b | 3 |

- ESP32 两个脚排分别落在 a 列和 j 列，占 30～44 排；这两列其余排数别再插别的器件。
- 每个器件脚所在那排的 c/d/e（或 f/g/h）都是空的，用来接线。
- BH1750 有 5 个脚，一排正好塞满 5 个孔，它那几排要并联相邻空排才够接线。

## 五、上电检查顺序

1. 先不插 ESP32，只接 3V3 / GND 两条轨，量两轨之间电阻，应该是几百欧以上（不是 0）。
2. 插上 ESP32，USB 供电，看串口有没有启动日志。
3. 再逐个插模块，每插一个看一次日志 —— 出问题能立刻定位是哪个模块。
4. OLED 应显示 `NO RTC`、温湿度、`----lx`；接上 DS3231 后用 `rtc_set` 校时。
5. 舵机**最后**接，并用独立 5V；插上舵机就重启的话，99% 是供电不足。

## 六、常见问题

| 现象 | 原因 |
| --- | --- |
| 模块插上后完全不工作 | 横着插在同一排，几个脚被短路了（一排 5 孔连通） |
| I2C 扫不到设备 | SDA/SCL 接反，或者链式跳线中间断了一节 |
| 只有 OLED 亮、传感器读不到 | 两块板之间的 4 根总线没接（板与板之间不连通） |
| 舵机一动就重启 | 舵机从 3V3 取电，或者没共地 |
| 屏幕花屏 | SCL 走线太长 / 杜邦线接触不良 / 电源不稳 |
| 温湿度一直 `NO CLIMATE DATA` | SHT30 的 ADDR 悬空或地址不对 |
